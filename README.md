# 👻 Haunted Terminal AI — The Forgotten Signal

**An AI-powered interactive mystery adventure built with Python and open-source AI.**

## About the Game

The year is 2026. An abandoned computer has suddenly awakened, transmitting a mysterious signal.

Inside the computer lives ECHO, a forgotten artificial intelligence that has lost its memories.

Your mission is to explore an abandoned building, collect clues, communicate with ECHO, and uncover the truth behind the forgotten signal.

## Features

- Five interconnected mystery locations
- Interactive text-based exploration
- AI-powered conversations using Google's FLAN-T5 Small model
- Five hidden clues
- Three possible endings
- Progress tracking 
- Free to run in Google Colab

## How to Play

1. Open the notebook in Google Colab.
2. Run the Python code.
3. Wait for the AI model to load.
4. Type `help` to see the available commands.
5. Explore rooms, collect clues, and solve the mystery.

## Commands

| Command | Description |
|---|---|
| `help` | Display all commands |
| `look` | Examine your surroundings |
| `explore` | Discover a hidden clue |
| `go library` | Travel to a connected room |
| `ask Who are you?` | Speak with ECHO |
| `clues` | Review collected clues |
| `map` | Display all locations |
| `status` | Check your progress |
| `unlock ECHO` | Attempt the final mystery |
| `exit` | Leave the game |
